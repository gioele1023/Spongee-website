# Spongee

Spongee ist eine Website für eine Firma, die verschiedene Schwämme für den Haushalt und die Garage anbietet. Die Website zeigt unsere Produkte und informiert über unsere Firma.

## Inhalt

* Startseite mit einer kurzen Geschichte über die Firma
* Übersicht der verschiedenen Produkte
* Kontaktbereich für Fragen und Anfragen

## Verwendet

* HTML für den Aufbau der Website
* CSS für das Design
* Bootstrap für das Layout und die Gestaltung

## Ziel

Das Ziel der Website ist es, unsere Produkte übersichtlich zu präsentieren. Die Website soll einfach zu bedienen sein und auch auf verschiedenen Geräten gut funktionieren.
